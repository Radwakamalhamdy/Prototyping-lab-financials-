# Prototyping Lab Financials

Financial tracking and management dashboard for the Prototyping Lab at the Faculty of Biotechnology, MSA University.

## 🚀 Features

- **Google Sheets / Spreadsheet Aesthetic**: Authentic cell gridlines, row number indicators, column letter tags (`A` to `E`), and live formula calculation bar (`ƒx`).
- **3 Segregated Financial Accounts**:
  - 🏗️ **Prototyping Lab Financials** (with official RDI watermark)
  - 🏛️ **UEC Financials** (with official UEC logo watermark)
  - 👨‍🏫 **Dr. Ahmed Gomaa Financials** (with Dr. Ahmed Gomaa photo watermark)
- **Financial Controls & Receipts**:
  - Track Item, Price (EGP), and InstaPay transaction receipt images.
  - Image preview lightbox with full zoom.
  - Live budget allocation tracking against **92,000 EGP** total received funds.
- **Executive Audit & Reporting**:
  - Live budget utilization progress bar.
  - Category breakdown with percentages and status pills.
  - Export to **CSV**, **Excel (.xls)**, **Word (.doc)**, and clean printable **PDF**.
- **Offline & Local-First**: Runs directly in the browser with `localStorage` persistence, no backend or database required.

## 🛠️ Built With

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla ES6+)
- LocalStorage API
